## Why this exists

Most wasted ad spend we see isn't a strategy problem. It's process: tracking nobody verified, Display expansion left on in a Search campaign, location targeting set to "interest", a negative list that was never applied, a report that lists metrics without saying what to do next.

These SOPs are the checklists we use at SOFTLOGIX Technologies for local and service businesses (ground transportation, movers, home services, professional services) across the US, UK, Canada, Australia, UAE and Pakistan. They're written so a new team member can follow them and a client can see exactly what's being done.

## The order matters

1. **Measure before you optimise.** SOP 01 section 2 comes before everything else. If conversions are wrong, every bid strategy is optimising toward the wrong thing.
2. **Build simple, then scale.** Fewer campaigns and ad groups with enough data beat many starved ones.
3. **Change one thing, log it, wait.** The weekly routine is built around that rule.

## Platforms change

Ad platforms change settings and defaults often. Treat these SOPs as a process, and check the platform's current interface and documentation when a setting has moved. Pull requests that update a step are welcome.
