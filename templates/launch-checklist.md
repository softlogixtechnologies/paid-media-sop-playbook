# Campaign launch checklist

Copy into the client folder and tick every box before enabling a campaign.

**Client:** ______ **Platform:** ______ **Campaign:** ______ **Launch date:** ______ **Checked by:** ______

## Tracking

- [ ] Primary conversion action(s) verified with a real test in the last 7 days
- [ ] No duplicate primary conversions for the same action
- [ ] Auto-tagging on (Google) / domain verified and CAPI deduplicating (Meta)

## Settings

- [ ] Correct campaign type and objective
- [ ] Networks: Search only; Display expansion **off** (Google Search)
- [ ] Locations correct, option set to **Presence**
- [ ] Languages correct
- [ ] Ad schedule matches business hours / phone coverage
- [ ] Budget matches the agreed monthly spend
- [ ] Bid strategy and any targets as planned

## Keywords and audiences

- [ ] Keyword match types as planned
- [ ] Negative keyword list(s) applied
- [ ] Brand exclusions applied (PMax)
- [ ] Audience signals / exclusions set

## Ads and assets

- [ ] Ads approved or pending only for normal review
- [ ] Final URLs load, are the right pages, and keep UTM / gclid parameters
- [ ] Phone numbers in ads and on landing pages are correct
- [ ] Sitelinks, callouts, snippets, call and location assets added

## Sign-off

- [ ] Client approved ads and budget in writing
- [ ] Change log updated with launch entry
- [ ] First check-in scheduled for tomorrow
