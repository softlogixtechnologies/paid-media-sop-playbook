# SOP 04: Meta Ads launch (Facebook + Instagram)

**Goal:** a lead or sales campaign that exits learning and produces trackable results. **Prerequisite:** Pixel + Conversions API live with event IDs and deduplication confirmed in Events Manager.

## 1. Measurement

- [ ] Main event (`Lead` or `Purchase`) fires from the browser and the server with the same event ID.
- [ ] Event Match Quality is reasonable for the main event; send hashed email and phone through CAPI to improve it.
- [ ] The domain is verified in the Business Portfolio.

## 2. Campaign structure

| Setting | Default |
|---|---|
| Objective | **Leads** (website or instant form) or **Sales** |
| Budget | Campaign-level (Advantage campaign budget) once you have more than one ad set |
| Ad sets | As few as possible. Meta's learning phase needs roughly 50 optimization events per ad set per week, and splitting budget across many ad sets slows that down |
| Audience | Broad or Advantage+ audience within the service area, with exclusions for existing customers if a list is available |
| Placements | Advantage+ placements unless a specific placement clearly underperforms |
| Conversion location | Website for higher-intent leads; instant forms for volume, with a qualifying question added |

## 3. Creative

Creative is the main targeting lever on Meta. Launch with 3 to 6 genuinely different concepts, not variations of one image:

- **Problem → solution:** the stress the service removes (missed flights, unreliable rides).
- **Proof:** reviews, years in business, fleet photos.
- **Offer:** a clear price signal or booking incentive.
- **Founder / team video:** short, vertical, shot on a phone, captions on.

Every ad: a clear hook in the first seconds, captions, the service area named, one call to action.

## 4. First 7 days

- Don't edit ad sets while they're in learning; significant edits can restart it.
- Check delivery and cost per result daily, but judge creative after it has had meaningful spend.
- Check lead quality with the client by day 3 for instant forms.

## 5. After learning

- Turn off concepts that are clearly behind on cost per result once they've had fair spend; introduce new concepts on a steady rhythm.
- Watch frequency and CTR trends for fatigue; refresh creative before results decline sharply.
- Scale budget gradually rather than in large jumps, which can destabilise delivery.
